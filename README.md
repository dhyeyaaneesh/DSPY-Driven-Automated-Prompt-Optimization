# DSPy-Driven Automated Prompt Optimization for Structured Medical Triage

## Project Overview
This project investigates the use of DSPy-driven automated prompt optimization to improve the accuracy and reliability of structured medical triage predictions.

## Objective
To compare manually designed prompts with DSPy-optimized prompts using a fixed underlying language model and task-specific evaluation metrics.
